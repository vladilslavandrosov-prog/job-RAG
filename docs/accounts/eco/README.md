# Аккаунт: «Эко» (производственная компания, СМК/пищевая безопасность)

> **Название компании не зафиксировано** — известен только рабочий домен на платформе «Эко» и пользователь `eco_user@itq-group.com`. Уточнить и вписать точное название компании, как только оно появится в материалах.

> **Не путать с другими аккаунтами.** В базе четыре разных, не связанных между собой заказчика:
> - **АО «Инвестиционная компания Д8»** — брокер, основной оплачиваемый пилот (материалы — в `docs/analysis/case-*`, `docs/platform/`, не в `docs/accounts/`).
> - **[`../mz-arsenal/README.md`](../mz-arsenal/README.md)** — ОАО «Машиностроительный завод «Арсенал», оборонное предприятие, тёплый лид на стадии демо.
> - **[`../dairy-holding/README.md`](../dairy-holding/README.md)** — молочный холдинг, пищевая отрасль, только что прошёл первую discovery-встречу.
> - **Этот аккаунт («Эко»)** — производственная компания (пищевая/потребительская продукция, судя по ссылкам на ISO 22000/ISO 9001 и цеховую документацию 1С-8), пилот **уже технически запущен на платформе** — есть живой пользователь, домен и коллекции документов, идёт тестирование ответов ассистента по СМК-регламентам.
>
> Если в переписке встречается просто «Эко» без уточнений — это про этот аккаунт, не про демо-кейс `docs/demo-sinaps/` или что-либо связанное с Д8.

## Что известно на данный момент

- **Платформенная идентичность:** пользователь `eco_user@itq-group.com`, без назначенной Персоны (RLS не настроен), с прямым доступом к домену **«Эко»** через роль `Domain Only Access Role`.
- **Домен «Эко»** содержит 3 коллекции: `eco` (misc), `Fedoseeva` (regulation), `uploads_user_eco_user__misc` (misc, похоже на личную папку загрузок самого `eco_user`) — подробности и открытые вопросы по настройке доступа см. [`access-audit.md`](access-audit.md).
- **Идёт пилотное тестирование ответов** ассистента по регламентам СМК (система менеджмента качества / пищевая безопасность): 6 групп вопросов от условных ролей сотрудников (начальник склада, технолог, мастер, оператор фасовки, механик, менеджер по продажам) — и отдельный разбор, где ответ платформы разошёлся с тем, что реально было в документах (файл «Ошибки Камераты»).

## Структура

- `source/` — исходные материалы по мере поступления: регламенты/инструкции СМК (`instrukciya-*`, `dokument-*`, коды вида `И-08-03-01`/`Д-08-04-01` из номенклатуры заказчика) и материалы пилотного теста (`pilot-smk-*`).
- `access-audit.md` — разбор прав пользователя `eco_user@itq-group.com` и структуры домена «Эко»: что настроено верно, что не настроено (RLS/Персона), открытый вопрос про дублирование документов между коллекциями.

Если понадобится текст именно из них — пересохраните на своей стороне в `.docx` и пришлите заново, либо укажите прямо, что в них, и я впишу это в таблицу выше.
