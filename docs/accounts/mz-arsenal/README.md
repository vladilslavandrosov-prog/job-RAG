# Аккаунт: ОАО «Машиностроительный завод «Арсенал»

Реальный, живой цикл продажи (не гипотетический кейс): ITQ ведёт переговоры с оборонным предприятием о внедрении корпоративной ИИ-платформы («Единый корпоративный ИИ-слой», тот же продукт, что разобран в `docs/sales-enablement/`). Материалы сюда добавляются по мере поступления новых встреч — это открытый, пополняемый аккаунт, а не разовый разбор.

Каждая встреча разбирается тремя ролями (аналитик — заинтересованность и квалификация заказчика; архитектор — технические требования и соответствие платформе; критик — сверка заявленного вживую с уже задокументированным и с собственным саммари вендора), с особым вниманием к вопросам и интересам заказчика.

## Структура

- `source/` — исходные материалы по каждой встрече (транскрипт + саммари вендора), в исходном docx и в очищенном markdown.
- `meeting-NN-analysis.md` — разбор каждой встречи по трём ролям + сводная оценка.
