Риски Что держать на контроле

Канал API/MCP заметно отстаёт от чата — 3 независимых сценария (анонимизатор-8, платформа-3, платформа-4) показывают, что деанонимизация или выбор источника данных ломаются именно при обращении через API/MCP
«Слетают» домен и персона — один и тот же баг зафиксирован в сценариях 1 и 2 блока «Платформа данных» (03.09, Горячев); похоже на общую инфраструктурную проблему, а не на два разных дефекта
«RAG-компании» — статус стал менее видимым: раньше это была отдельная дорожка с нулевым движением, теперь — один пункт в общем списке источников без отдельной строки. Подтверждения, что риск снят, нет
Семантический слой CRM+DWH (платформа-5) — по-прежнему не настроен, комментарий в трекере дословно повторяет более раннюю формулировку

9 + 6 Не входило в первоначальный план пилота

Пилот по «Общему описанию» — это стенд + 2 источника (КХД, ESB) + 2 роли + RAG-корпус из 2 коллекций + AI Guard на одну облачную LLM + до 20 пользователей. Всё ниже — то, что появилось поверх этого объёма в ходе работы.

Новые требования из журнала (9)

  • Отображать список базовых маскируемых типов PII
  • Упорядочивание сессий по времени последней активности + фильтр «Только активные» В РАБОТЕ
  • Прямой доступ через API (сейчас — только штатный интерфейс чата)
  • Поддержка эндпоинта, отвечавшего 403 (за рамками API)
  • Разбор xml и pptx документов
  • Отдельная настройка NER-модели («не в рамках пилота»)
  • Отрисовка диаграмм (например, Ганта) в чате
  • Выбор контура/источника данных в интерфейсе пользователя ГОТОВО
  • Баг с таймаутом в пререлизном интерфейсе

Согласованный бэклог «Доработки» (6)

  • Мультидоменная авторизация
  • Работа с MS Office 365 (сейчас — только Gmail/IMAP)
  • Актуальная версия API Claude (web search и т. п.)
  • Выбор источника данных в интерфейсе пользователя
  • Разбор pptx и xml документов
  • Именование замен по кастомным правилам, не как CUSTOM_N

Ни один из этих 15 пунктов не блокирует приёмку исходного объёма пилота — но каждый стоит явно развести с ТЗ при подведении итогов, чтобы не выглядеть как невыполненное обязательство.
