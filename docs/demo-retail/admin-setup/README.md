# Инструкция администратора: настройка платформы к демонстрации

Внутренний материал (не для клиента) — пошаговая инструкция для того, кто готовит стенд «Синапс.Инсайт» к живой демонстрации ретейл-кейса «ТоргЛайн». В отличие от `docs/demo-retail/presentation/` (продающий материал для встречи с клиентом), это операционный чек-лист для администратора платформы.

- [`admin-setup-guide.pptx`](admin-setup-guide.pptx) — 10 слайдов: обзор, структура доменов/коллекций, порядок загрузки документов, устройство «Графа доступа», конкретная настройка трёх персон для Сценария 2 (разграничение доступа по ролям), проверка перед показом, что из «Управление данными» для этого кейса настраивать не нужно (Граф процедур, Граф код→таблица — не относятся к ретейл-кейсу без кода/хранимых процедур), итоговый чек-лист, ссылки на источники.

Все факты и конфигурация (список файлов по коллекциям, три персоны и их row-фильтры/маски) взяты из уже существующего runbook — [`docs/demo-retail/dataset/README.md`](../dataset/README.md) — и из описания экранов платформы — [`docs/platform/istochniki-dokumenty.md`](../../platform/istochniki-dokumenty.md) и [`docs/platform/upravlenie-dannymi.md`](../../platform/upravlenie-dannymi.md). Презентация не вводит новых фактов, только собирает их в пошаговый порядок действий.

## Ограничение проверки

LibreOffice в этой песочнице не запускается, визуальный рендер слайдов был недоступен. Файл прошёл схемную валидацию (`validate.py` — «All validations PASSED») и текстовую проверку (`markitdown`) без расхождений; расположение элементов на слайдах пересчитано вручную по ширине блоков, но перед использованием стоит самим пролистать слайды.
