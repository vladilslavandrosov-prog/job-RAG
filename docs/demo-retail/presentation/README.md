# Презентационные материалы: вопросы и ответы

Дополнительные материалы к 8 демо-сценариям (`docs/demo-retail/scenarios.md`) — для подготовки к встрече и для того, чтобы держать вопросы/ответы под рукой во время презентации. Это не замена самой демонстрации: живой показ по-прежнему проходит в платформе на пакете документов из `docs/demo-retail/dataset/`.

- [`retail-qa-presentation.pptx`](retail-qa-presentation.pptx) — слайд-дека: по одному слайду на сценарий (вопрос → ожидаемый ответ → какую возможность платформы это доказывает), плюс титульный, вводный и итоговый слайды.
- [`retail-qa-doc.docx`](retail-qa-doc.docx) — тот же материал полным текстом, без сокращений слайдов: удобно как справка докладчика или как самостоятельный документ для рассылки клиенту.

Оба файла построены на одних и тех же вопросах и ожидаемых ответах, что и `docs/demo-retail/dataset/README.md` — числа и факты в них соответствуют данным, реально заложенным в документы пакета «ТоргЛайн».

## Ограничение проверки

В этой песочнице не работает LibreOffice (`soffice` не может открыть даже тестовый файл), поэтому визуальный рендер слайдов/страниц в картинки для QA был недоступен. Оба файла проверены схемной валидацией (`validate.py`, обе — «All validations PASSED») и текстовым извлечением (`markitdown`/`pandoc`) — по содержимому и структуре расхождений не найдено, но итоговую вёрстку стоит визуально пролистать перед показом клиенту.
