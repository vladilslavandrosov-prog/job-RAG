# Политика предоставления скидок (редакция v2, действует с 01.04.2025)

**ДЕМО-ДОКУМЕНТ. АКТУАЛЬНАЯ РЕДАКЦИЯ.**

## 1. Общие правила
1.1. Настоящая редакция отменяет и заменяет редакцию v1 от 12.01.2024.
1.2. Максимальная суммарная скидка к прайсу — **до 12%** без дополнительного согласования.

## 2. Пороги согласования
2.1. Скидка до 12% — на усмотрение руководителя направления.
2.2. Скидка 12–18% — согласование с финансовым директором.
2.3. Скидка свыше 18% — только по эксклюзивным договорам, решение генерального директора.

## 3. Региональные акции
3.1. В рамках квартальных акций допускается повышенная скидка в отдельных регионах при согласовании с финансовым директором (например, программа стимулирования продаж в Южном регионе в Q3 2025 — до 12%).
