# Политика информационной безопасности и обработки ПДн при работе с ИИ

**ДЕМО-ДОКУМЕНТ.**

## 1. Принцип
1.1. Данные не покидают периметр компании в открытом виде. Любой запрос к внешней модели проходит через контролируемый шлюз (AI Guard).

## 2. Персональные данные
2.1. ПДн (ФИО, телефоны, e-mail, ИНН физлиц) маскируются токенами до отправки во внешнюю модель; пользователю ответ возвращается деанонимизированным (152-ФЗ).

## 3. Коммерческая тайна
3.1. Темы из «базы секретов» (эксклюзивные условия, плановые показатели до объявления, суммы незакрытых сделок, параметры M&A) во внешние модели не передаются.
3.2. Реакция определяется матрицей доверия: ALLOW (внутренняя модель) / REVIEW (решает сотрудник ИБ) / BLOCK.

## 4. Доступ
4.1. Права наследуются из систем-источников (RBAC). Пользователь видит в ответах ИИ только то, к чему имеет доступ в исходных системах.

## 5. Аудит
5.1. Каждый запрос и ответ, а также каждый выход агента во внешнюю сеть журналируется.
