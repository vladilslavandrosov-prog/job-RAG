# Политика возвратов сети «Полка»

**ДЕМО-ДОКУМЕНТ.**
1. Возврат надлежащего качества — 14 дней (кроме товаров из перечня невозвратных).
2. Брак/гарантийный случай — обмен или возврат средств, срок рассмотрения до 10 дней.
3. Повреждение при доставке — фиксируется при приёмке, возврат за счёт сети.
4. Причины возврата классифицируются для аналитики качества (см. tickets/returns).
