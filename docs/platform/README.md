# База знаний по платформе «Синапс.Инсайт»

AI-платформа корпоративных данных. Документация собирается по мере поступления скриншотов интерфейса — каждый экран/раздел оформляется отдельной статьёй: назначение, элементы управления, поля, наблюдения и связь с ТЗ/глоссарием проекта.

## Структура платформы (по левому меню, по мере изучения)

- **Чат** — [описан](chat.md): история диалогов, выбор модели/агента, экспорт в PDF, переключатель «Рассуждения»
- **Мои шаблоны** — [описан](moi-shablony.md): курируемые образцы ответов, recall на похожий вопрос, строгий vs обычный режим
- **Источники**
  - [Документы](istochniki-dokumenty.md) — реестр загруженных источников, статус индексации, фрагменты, домены/коллекции
- **Задачи** — [описан](zadachi-review-pipeline.md) целиком, как единый конвейер модерации:
  - Предложения — очередь одобрения терминов/документов (469 предложений, мульти-доменность платформы)
  - Агенты на утверждении (DS) — двухступенчатое согласование агентов (утверждение → ревью ИБ)
  - Статистика — сводка по очереди (469 всего, 92 «ошибки индексации»)
  - Очередь обработки — живой дашборд воркеров (упавшие/зависшие задачи)
  - Промпты персон — ролевые промпты для системного чата vs «канвасные» (governed) агенты
- **Калибровка**
  - [Калибровка детектора](kalibrovka-detektora-i-otladka.md) — пороги детектора таблиц, вкладки (чанкинг, документы, обслуживание, корни measure)
  - [Политики поиска](kalibrovka-politiki-poiska.md) — ранжирование чанков по интенту, планировщик/реплан при низкой уверенности, роутинг вопросов
  - [Отладка сессий](kalibrovka-detektora-i-otladka.md) — разбор диалогов (инструменты/план/ответы); ⚠ аудит-БД не сконфигурирована
- **Управление данными** — [частично описан](upravlenie-dannymi.md):
  - Анализ схем — анализ схемы таблицы по FQN
  - Граф процедур — lineage хранимых процедур, инкремент по hash
  - Граф код→таблица — не описан
  - Граф доступа — не описан
- **Каталог** — не описан
- **Агенты** — не описан
- **Администрирование** — не описан
- **Мониторинг** — не описан

## Сквозные находки (по всей платформе)

- **Мульти-доменность**: платформа одновременно обслуживает минимум три предметные области — брокер/инвестиции (исходное ТЗ), охрана труда/производство (`OT-*` документы), кредитный риск/взыскание (глоссарий в «Предложениях»). См. `zadachi-review-pipeline.md`.
- **Аудит-БД не сконфигурирована**: штатный инструмент разбора диалогов («Отладка сессий») существует в продукте, но не работает в этом окружении — прямое объяснение, почему разбор Кейса 01 пришлось делать вручную по тексту ответа. См. `kalibrovka-detektora-i-otladka.md`.
- **OpenAI/gpt-5.4 в селекторе модели** — потенциальное противоречие с требованием ТЗ «данные не покидают периметр компании». См. `chat.md`.
