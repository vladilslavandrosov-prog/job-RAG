# Раздел «Источники → Документы»

Реестр всех документов, загруженных в платформу как источники для RAG-индексации. Экран показывает, что загружено, в каком статусе обработка, к какой коллекции и домену относится документ и сколько фрагментов (чанков) из него получилось после индексации.

## Действия

- **+ Загрузить файл** — добавить один документ вручную.
- **+ Директорию** — подключить целую директорию как источник, с пакетной загрузкой и синхронизацией папки.

**Модалка «Загрузка документа» (17.08.2026):** после выбора файла открывается форма с полем **«Назначение»** — два варианта:
- **«В коллекцию»** — документ привязывается к конкретной коллекции; если подходящей ещё нет, её нужно создать заранее. **Важный нюанс:** создавать коллекции может только администратор — обычный пользователь при загрузке только выбирает из уже существующих.
- **«Личные документы»** (по умолчанию) — коллекция не нужна вообще. Файл уходит в личное пространство (`uploads`), без домена, а доступ к нему определяется отдельным переключателем видимости: **«Только мне»** / **«Команде»** / **«Всем»** — вместо членства в коллекции.

То есть коллекция обязательна только на пути «В коллекцию»; чтобы обойтись без неё, при загрузке достаточно оставить «Личные документы» и выбрать нужную видимость.

## Фильтры и поиск

Панель фильтров: по коллекции, по типу коллекции, по типу документа (`Другое`, `Регламент`, `Политика` и другие), по видимости, по домену, по статусу обработки, а также чекбокс «Комментарии». Отдельная строка полнотекстового поиска по имени файла.

## Колонки таблицы

Файл, Тип, Коллекция, Домен, Статус, Фрагменты (число чанков после индексации), Размер, Видимость, Владелец, Дата.

Документ классифицируется сразу по трём независимым осям — коллекция, домен и тип, — что даёт более гранулярную таксономию, чем просто деление по источнику данных. Число фрагментов не обязательно пропорционально размеру файла: у документов одинакового размера оно может отличаться, поскольку зависит скорее от количества смысловых разделов в тексте, чем от объёма в байтах.
