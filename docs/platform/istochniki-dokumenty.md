# Раздел «Источники → Документы»

> Скриншот: список документов платформы «Синапс.Инсайт» (`Разделы → Источники → Документы`).

## Назначение экрана

Это реестр всех документов, загруженных в платформу как источники для RAG-индексации. Отсюда видно: что загружено, в каком статусе обработка, к какой коллекции/домену относится документ, сколько фрагментов (чанков) из него получилось после индексации — прямая связка с процессом «загрузки документов», описанным в [`docs/glossary/rag-document-ingestion.md`](../glossary/rag-document-ingestion.md).

Заголовок «Документы (18)» — общее число документов, видимых при текущих фильтрах.

## Действия

| Кнопка | Назначение |
|---|---|
| **+ Загрузить файл** | Добавить один документ вручную (разовая загрузка) |
| **+ Директорию** | Подключить целую директорию как источник (пакетная загрузка/синхронизация папки) |

## Панель фильтров

| Фильтр | Что делает |
|---|---|
| Все коллекции | Фильтр по коллекции документов (логическая группа, в примере — `AZ_tech`) |
| Все типы коллекций | Фильтр по типу коллекции (более широкая категория, чем «коллекция») |
| Все типы | Фильтр по типу документа (`Другое`, `Регламент`, `Политика` и т.п. — см. колонку «Тип») |
| Любая видимость | Фильтр по уровню видимости документа (в таблице — колонка «Видимость», пример значения: `Доменная`) |
| Домен (на скриншоте выбрано «Производство») | Фильтр по бизнес-домену, к которому отнесён документ |
| Все статусы | Фильтр по статусу обработки (пример: `Готово`) |
| ☐ Комментарии | Чекбокс — вероятно, показывать только документы с комментариями |

Отдельно — строка поиска по имени файла, с явной подсказкой в плейсхолдере: «пробел = любая подстрока» (то есть пробел в запросе работает не как разделитель отдельных слов AND/OR, а как символ, допускающий любую подстроку между частями — стоит уточнить точную семантику отдельно, неочевидно из UI).

## Колонки таблицы

| Колонка | Описание | Пример со скриншота |
|---|---|---|
| Файл | Имя файла + иконка типа | `OT-10_Zhurnal_registratsii_instruktazhey.docx` |
| Тип | Категория документа | `Другое`, `Регламент...`, `Полити...` |
| Коллекция | Логическая группа документов | `AZ_tech` |
| Домен | Бизнес-домен | `Производство` |
| Статус | Результат обработки/индексации | `✅ Готово` |
| Фраг. (Фрагменты) | Количество чанков, на которые документ был разбит при индексации | от 2 до 16 в примере |
| Размер | Размер файла | `38 КБ` / `53 КБ` |
| Видимо... (Видимость) | Уровень доступа к документу | `Доменная` |
| Владелец | Кто загрузил документ | `maria` |
| Дата | Дата загрузки/обработки | `22.07.2026` |
| ... | Меню действий по строке (не раскрыто на скриншоте) | — |

## Наблюдения и связи с ТЗ / глоссарием

- Колонка **«Фрагменты»** — это ровно то число чанков, о котором речь в статье глоссария про загрузку документов: у документа `OT-10_...` (16 фрагментов) и `OT-08_Polozhenie_o_rassledovanii_NS.pdf` (3 фрагмента) сильно разное дробление — разумно предположить, что оно зависит от объёма/структуры исходного файла, но при одинаковом размере файла (`53 КБ` у нескольких документов) число фрагментов отличается (`3`, `2`, `2`) — стоит уточнить логику chunking (возможно, зависит не от размера в байтах, а от количества смысловых разделов/абзацев в документе).
- Статус **«Готово»** у всех видимых строк — не видно ни одного примера ошибки обработки; полезно будет задокументировать отдельно, как выглядит неуспешный статус, когда до него дойдёт скриншот.
- Разделение **Коллекция / Домен / Тип** — три независимых способа классификации одного документа. Это шире, чем структура источников в самом ТЗ (там документы делятся только по источнику — CRM/Excel/Word-PDF/Email и по критичности), то есть реальная платформа вводит более гранулярную таксономию, чем было явно описано в ТЗ.
- **Владелец** (`maria`) — привязка документа к конкретному пользователю, загрузившему файл; это может быть основой для разграничения прав доступа (см. `case-02-tz-deep-analysis-and-proposals.md`, п. 2.3/4.5 — вопрос ролевого доступа).

## Открытые вопросы (уточнить на следующих скриншотах)

- Что означают все возможные значения «Тип» документа помимо `Другое`, `Регламент`, `Политика`?
- Что находится в меню «...» по каждой строке (просмотр фрагментов? повторная индексация? удаление?)
- Как выглядит статус, отличный от «Готово» (в процессе обработки, ошибка)?
- Полный список доменов и коллекций, кроме `Производство` / `AZ_tech`.
