# Раздел «Калибровка»: детектор таблиц и отладка диалогов

## Калибровка детектора таблиц

Инструмент настройки детектора, который на этапе индексации определяет, является ли фрагмент документа таблицей, и выставляет соответствующие метаданные (`is_table`), которые затем использует политика ранжирования `таблица-схема-boost` в разделе «Политики поиска». Экран организован во вкладки: «Калибровка порогов» (настройка порогов срабатывания детектора, с выбором коллекции), «Чанкинг» (разбиение табличного контента на фрагменты), «Документы» (проверка детекции на конкретных документах), «Обслуживание» (служебные операции) и «Корни measure» — настройка отдельного range-роутера, отвечающего за маршрутизацию вопросов про числовые диапазоны и меры.

## Отладка сессий

Инструмент разбора диалогов пользователей: список сессий с поиском по пользователю, а клик по конкретному диалогу раскрывает разбор сессии — использованные инструменты, построенный план, полученные ответы. Это ровно тот уровень детализации, который нужен для диагностики сбоев RAG-агента: какой SQL был сгенерирован, какие фрагменты найдены, по какому плану строился ответ.

В текущем окружении экран показывает предупреждение «Аудит-БД не сконфигурирована», и список диалогов пуст. Функция в продукте существует, но не подключена в этом развёртывании — то есть штатный способ разобрать конкретную сессию сейчас недоступен, и подробный разбор приходится делать вручную, по тексту ответов агента в самом чате.
