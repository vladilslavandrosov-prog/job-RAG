# Раздел «Мои шаблоны»

Механизм курируемых образцов ответов. Администратор или аналитик заранее задаёт пару «вопрос-триггер → образец ответа»; когда пользователь в чате задаёт похожий вопрос, система подставляет этот образец вместо того, чтобы генерировать ответ с нуля.

## Форма создания шаблона

- **Вопрос-триггер** — формулировка вопроса, при похожести на которую сработает шаблон (recall).
- **Ответ-образец** — текст шаблона ответа.
- **График** — тип графика, если ответ должен его включать.
- **таблица** — ответ включает табличную форму.
- **строгий шаблон** — переключает режим применения (см. ниже).

## Два режима применения

В обычном режиме текст ответа берётся из шаблона (структура, тон, формулировки), но форма — график или таблица — пересчитывается по свежим данным на момент вопроса: шаблон фиксирует, *как* отвечать, а не то, какие именно цифры были в прошлый раз. В строгом режиме ответ возвращается как есть, только с подстановкой актуальных данных вместо значений шаблона.

Тексты шаблонов обезличены: сам образец не должен содержать реальные данные конкретного клиента, только структуру ответа.

## Отличие от памяти сессии

Шаблоны — это отдельный от памяти диалоговой сессии механизм повторного использования ответов: они заводятся вручную куратором и действуют кросс-сессионно, для любого пользователя, задавшего похожий вопрос, тогда как память сессии переиспользовала бы уже полученный результат внутри одного конкретного диалога. Шаблон с триггером вида «собери бриф к встрече с клиентом» и образцом, повторяющим нужную структуру (портрет → позиции → динамика → обращения), обеспечивает, что итоговый ответ на такой запрос всегда идёт по одной и той же надёжной структуре, при этом каждый раз пересчитывая данные заново.
