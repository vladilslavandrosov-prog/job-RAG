# «Единый корпоративный ИИ-слой» — версия в стиле ТЗА

`korporativny-ai-sloy-prezentatsiya-tza-style.pptx` — та же самая презентация из `../source/korporativny-ai-sloy-prezentatsiya.pptx` (12 слайдов, содержание один в один, без изменений), но пересобранная визуально под стиль шпаргалки кейса ТЗА («Три уровня возможностей RAG-агента», см. `docs/demo-retail/`).

## Что взято из стиля ТЗА

- Палитра: тёмно-синий `0F2A4A` (доминирующий), оранжевый `E87A1E` (акцент/kicker), бирюзовый `1A7A68` (третий акцент); приглушённый серый `555B66` для основного текста.
- Шрифт Calibri везде, только прямоугольники — ни одной скруглённой формы.
- Единый заголовок страницы: эйбрау (маленькая надпись капсом) + крупный заголовок + тонкая оранжевая линия-подчёркивание + бейдж номера страницы «NN / 12» справа.
- Пронумерованные 3-колоночные блоки (крупная цифра/заголовок/акцентная линия/описание, цвет ротируется навy → оранжевый → бирюзовый) — для параллельных категорий (слайды 2, 6, 11).
- Тонкие вертикальные и горизонтальные линии-разделители вместо рамок и заливок карточек.
- Тёмно-синие развороты для первого и последнего слайда (обложка / контакты) — по аналогии с единственным тёмным слайдом референса, распространено на оба «буклетных» края этой презентации.

## Почему это отдельный файл, а не замена исходника

Исходная презентация (`../source/korporativny-ai-sloy-prezentatsiya.pptx`) — это оригинал, полученный от команды продаж как есть. Версия в стиле ТЗА — это визуальный эксперимент по унификации визуального языка внутренних материалов (сейлз-питч + демо-шпаргалки одним стилем). Содержание не менялось: те же 9 разделов питча, те же кейсы клиентов, тот же график падения стоимости сценария, те же контакты менеджера.

## Ограничение QA

В этой песочнице не работает визуальный рендер PPTX (LibreOffice/`soffice` не конвертирует файлы) — проверка прошла через `markitdown` (полнота контента) и `scripts/office/validate.py` (схема/структура OOXML), плюс ручной расчёт EMU-координат и размеров шрифта на переполнение. Перед показом клиенту стоит один раз открыть файл в PowerPoint и визуально пролистать.
