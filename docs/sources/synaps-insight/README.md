# Синапс.Инсайт — официальная документация разработчика

16 документов от команды платформы (получены 19.08.2026), подтверждающие, что продукт за экраном `aiplatform.iqi.internal`, изученным весь этот проект по скриншотам — это **Синапс.Инсайт**.

## Руководства для ИТ/DevOps

- `doc1-install-guide.md` — установка и развёртывание (зональный дистрибутив: Зона 0 «Фундамент», Зона 1 «Core», Зона 2 «Синапс.Данные», Зона 3 «Синапс.Агенты»)
- `doc2-admin-guide.md` — руководство администратора (пользователи/роли, источники данных, коллекции, бэкапы, обновление, мониторинг)
- `doc2a-troubleshooting.md` — приложение А, 9 типовых проблем эксплуатации
- `doc3-sec-admin-guide.md` — руководство администратора безопасности (пользователи, роли, OPA-политики, PII Shield, аудит, реагирование на инциденты)
- `doc4-arch.md` — описание архитектуры и технических решений (компоненты, хранилища, ADR)
- `doc5-security-passport.md` — паспорт безопасности (ФЗ-152, ФСТЭК №17/21, guard rails, модель угроз)

## Руководства администратора (функциональные модули)

- `doc6-collections.md` — управление коллекциями документов
- `doc7-providers-models.md` — провайдеры и управление моделями (LLM/эмбеддеры)
- `doc8-budgets-rights.md` — бюджеты, тарифы и права пользователей

## Руководство пользователя (`ug_*`)

- `ug-01-start.md` — начало работы
- `ug-02-chat.md` — чат с помощником (подробно)
- `ug-03-documents.md` — документы: загрузка и коллекции

## Как использовать

Это первоисточник — не редактировать. Расхождения/подтверждения по сравнению с тем, что задокументировано в `docs/platform/*.md` по скриншотам живой системы, разбираются отдельно (см. анализ в этой же директории, если он появится, и обновления `docs/platform/otkrytye-voprosy.md`).
