## Введение

Настоящий документ описывает порядок установки и первоначального развёртывания платформы Синапс.Инсайт. Документ предназначен для инженеров ИТ-эксплуатации, выполняющих первичную инсталляцию системы.

Платформа поставляется в виде зонального дистрибутива: каждая зона представляет собой логически завершённый функциональный блок, который устанавливается независимо. Установка выполняется последовательно: сначала обязательные зоны (0 и 1), затем --- опциональные (2 и 3) в любом порядке.

Соглашения о терминах и обозначениях:

  -------------------------- ---------------------------------------------------------------------------
  **Термин / обозначение**   **Значение**

  Зона                       Логический блок дистрибутива с определёнными компонентами и зависимостями

  Синапс.Каталог             Компонент каталога данных и пользователей на базе OpenMetadata

  Синапс.Агенты              Агентская подсистема на базе LangGraph + LangFlow

  Синапс.Данные              Подсистема полнотекстового поиска и ingestion на базе OpenSearch

  TEI                        Text Embeddings Inference --- сервис векторизации текста

  \<PLACEHOLDER\>            Значение, которое необходимо подставить при установке

  /opt/synapse/              Корневая директория установки (можно изменить)
  -------------------------- ---------------------------------------------------------------------------

## Архитектура зонального дистрибутива

Платформа разделена на четыре зоны. Зоны 0 и 1 обязательны для любой инсталляции. Зоны 2 и 3 опциональны и независимы друг от друга --- каждая требует только наличия Зоны 1.

+---------------------------+---------------------+--------------------+---------------------+
| **Зона 0**                | **Зона 1**          | **Зона 2**         | **Зона 3**          |
|                           |                     |                    |                     |
| Фундамент                 | Core                | Синапс.Данные      | Синапс.Агенты       |
|                           |                     |                    |                     |
| PostgreSQL                | Qdrant / MinIO      | (опционально)      | (опционально)       |
|                           |                     |                    |                     |
| dlp-secret (+ ib_ui)      | TEI ×2              | Ingestion-пайплайн | LangFlow            |
|                           |                     |                    |                     |
| pii-shield                | dwh, ds-workstation | полнотекстового    | Langfuse            |
|                           |                     | поиска             | (LLM observability) |
|                           |                     |                    |                     |
| audit-service              | agent-runtime       |                    |                     |
|                           |                     |                    |                     |
| Redis                      | orchestrator        |                    |                     |
|                           |                     |                    |                     |
|                           | Синапс.Каталог      |                    |                     |
|                           | (OpenMetadata       |                    |                     |
|                           | + OpenSearch)       |                    |                     |
|                           |                     |                    |                     |
|                           | Nginx               |                    |                     |
+---------------------------+---------------------+--------------------+---------------------+
| **Зона 1 требует Зону 0** |                     | **Требует Зону 1** | **Требует Зону 1**  |
+---------------------------+---------------------+--------------------+---------------------+

  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Примечание:** Зоны 2 и 3 можно установить в любом порядке и в любое время после завершения Зоны 1. Установка одной опциональной зоны не требует и не влечёт установку другой.

## Чеклисты предварительных требований

>
> **☐** Все целевые серверы соответствуют минимальным аппаратным требованиям
>
> **☐** Docker Engine 24.0+ и Docker Compose v2.20+ установлены на всех хостах
>
> **☐** Сетевая связность между хостами платформы проверена
>
> **☐** На всех хостах настроен firewalld: IP смежных хостов добавлены в зону trusted
>
> **☐** Корневая директория /opt/synapse/ создана, права доступа настроены
>
> **☐** DNS-имена или /etc/hosts-записи настроены для всех компонентов

> **☐** Определён вариант PostgreSQL: локальный или клиентский экземпляр
>
> **☐** (если локальный) Сервер соответствует требованиям: 4 vCPU, 8 ГБ RAM, 100 ГБ SSD

> **☐** Список SAN сертификата включает все домены платформы (app.\*, om.\*, dlp.\*)

### 4.2 TLS-сертификат

Поместить сертификат и ключ в /opt/synapse/front/ssl/. Сертификат должен покрывать все домены платформы.

+--------------------------------------------------------------------------------------------------------------+
| \# Самоподписанный (для пилота/PoC):                                                                         |
|                                                                                                              |
| openssl req -x509 -nodes -days 365 -newkey rsa:2048 \\                                                       |
|                                                                                                              |
| -keyout /opt/synapse/front/ssl/tls.key \\                                                                    |
|                                                                                                              |
| -out /opt/synapse/front/ssl/tls.crt \\                                                                       |
|                                                                                                              |
| -subj \'/CN=app.example.local\' \\                                                                           |
|                                                                                                              |
| -addext \'subjectAltName=DNS:app.example.local,DNS:om.example.local,DNS:dlp.example.local,IP:\<SERVER_IP\>\' |
|                                                                                                              |
| \# Production --- разместить файлы от корпоративного УЦ:                                                     |
|                                                                                                              |
| cp /path/to/corp.crt /opt/synapse/front/ssl/tls.crt                                                          |
|                                                                                                              |
| cp /path/to/corp.key /opt/synapse/front/ssl/tls.key                                                          |
+--------------------------------------------------------------------------------------------------------------+

  ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **⚠ Внимание:** Самоподписанный сертификат необходимо добавить в доверенные хранилища всех клиентских машин. Без этого SSO Синапс.Каталога не будет работать (Service Worker блокируется браузером).

  ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

### 5.4 agent-runtime и orchestrator

|                                                                       |

|                                                                       |
| PG_HOST=postgres                                                      |
|                                                                       |
| PII_TRUSTED_EGRESS_TOKEN=\<тот же токен что в pii-shield.env\>        |
|                                                                       |
| PUBLIC_ORIGIN=https://app.example.local                               |
|                                                                       |
| GATEWAY_LOGIN_REDIRECT=https://app.example.local/                     |
|                                                                       |
| \# /opt/synapse/zone1/orchestrator.env:                               |
|                                                                       |

|                                                                       |
