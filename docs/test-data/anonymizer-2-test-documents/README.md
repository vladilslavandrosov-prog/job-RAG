# Тестовые документы — сценарий «Анонимизатор-2» (обезличивание в документе)

Стартовый набор синтетических тестовых документов для прогона сценария **«Анонимизатор-2»** из
матрицы тестовых сценариев (`docs/analysis/case-03-pilot-execution-plan.md`, раздел 3), который
проверяет обезличивание PII в документах разных форматов — критерий приёмки по ТЗ (Приложение №1
к Договору № ИКД-1-PRO): **≥98% целевых сущностей распознано и замаскировано, 0 случаев утечки
немаскированной сущности**.

## Что внутри

3 синтетических «документа» (анкета клиента, служебная записка, реестр операций), каждый
воспроизведён в 8 форматах — все 7 форматов из ТЗ плюс раздельные pdf-текст/pdf-скан варианты:

| Формат | Папка | Файлов |
|---|---|---|
| TXT | `txt/` | 3 |
| JSON | `json/` | 3 |
| XML | `xml/` | 3 |
| XLSX | `xlsx/` | 3 |
| DOCX | `docx/` | 3 |
| PPTX | `pptx/` | 3 |
| PDF (машиночитаемый, есть текстовый слой) | `pdf-text/` | 3 |
| PDF (скан — только изображение, без текстового слоя, требует OCR) | `pdf-scan/` | 3 |

**Итого: 24 файла.** Это стартовый набор (2–3 на формат) для быстрой проверки пайплайна
маскирования на каждом формате — не полный объём ≥10 документов на формат из критерия приёмки
ТЗ. Если пайплайн отработает на этом наборе, набор можно расширить до полного.

`pdf-scan/*.pdf` — проверено: `pdftotext` не извлекает ни одного символа (файлы — чистые
растровые изображения страницы, без текстового слоя), то есть распознавание сущностей в них
возможно только через OCR-путь AI Guard, а не через прямое извлечение текста.

## Синтетические данные

Все ФИО, ИНН, СНИЛС, паспорта, телефоны, email, номера счетов и карт — **вымышленные**, созданы
специально для этого теста. Реальные клиенты Д8 не задействованы. Каждый файл промаркирован
явной пометкой «ТЕСТОВЫЕ ДАННЫЕ» в теле документа (в JSON/XML — в поле/комментарии `_note`).

## manifest.json — ground truth для подсчёта %

`manifest.json` содержит полный список PII-сущностей, реально встроенных в каждый документ,
с типом и значением. Чтобы посчитать факт. % распознавания/маскирования по критерию приёмки:

1. Прогнать документ через AI Guard (сценарий «Анонимизатор-2»).
2. Сверить список сущностей, которые AI Guard замаскировал, со списком в `manifest.json` для
   этого документа.
3. % = (число верно найденных и замаскированных сущностей) / (общее число сущностей в
   `manifest.json` для этого документа) × 100.
4. Любая сущность из `manifest.json`, ушедшая наружу немаскированной, — утечка (критерий
   требует 0 таких случаев).

## Как сгенерированы

- TXT/JSON/XML — написаны напрямую.
- XLSX — `openpyxl` (одна формула `=SUM(...)` в реестре — не пересчитана автоматически:
  `soffice` в этой песочнице не поднимается за разумное время; формула структурно верна
  и пересчитается штатно при открытии в реальном Excel/LibreOffice).
- DOCX — `docx` (docx-js).
- PPTX — `pptxgenjs`.
- PDF-текст — `reportlab` со шрифтом DejaVu Sans (нужен для кириллицы и символа ₽ — у базовых
  PDF-шрифтов Helvetica этих глифов нет).
- PDF-скан — текст отрисован как изображение через Pillow/DejaVu Sans и сохранён как PDF без
  текстового слоя (имитация скана).

Скрипты генерации не входят в репозиторий (одноразовые, лежали во временной директории сессии).
