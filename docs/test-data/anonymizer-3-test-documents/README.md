## Предварительное наблюдение (не полный разбор)

При беглом просмотре первого скриншота (`image1.png`, документ `01_vypiska_bank.txt`) заметна вероятная ошибка классификации: сумма поступления «+3 450 000,00 RUB» размаскирована в маппинге как `[PHONE_1] → +3 450 000` — то есть денежная сумма распознана как номер телефона. При этом «отвлекающий» тестовый счёт `00000000000000000000` корректно остался немаскированным, как и предполагалось пометкой в исходном документе. Остальные 9 кейсов пока не разобраны подробно.

## Как использовать

Не первоисточник для правки — черновой набор для тестирования. Полный разбор (что должно маскироваться в каждом документе, что реально замаскировано, расхождения) будет оформлен отдельным кейсом в `docs/analysis/` после того, как накопление материалов завершится.
